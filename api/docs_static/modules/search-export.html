搜索与导出

场景 按多维条件检索在轨目标群体，一键导出为 Excel（xlsx），用于离线分析、报告与归档。

「搜索与导出」是在「目标目录」之上的分析型检索页面：它实时关联 SATCAT（Space-Track）、最新 GP/TLE 轨道根数、 UCS 运营卫星库 与 ESA DISCOS，并即时计算每个目标的 轨道高度、线/角速度、太阳同步判定、受控（推定）、质量与尺寸， 再按条件筛选、一键导出。前端页面与 REST API 同源（analytics/catalog_search.py）。

使用步骤

  1. 在左侧导航栏点击 「搜索与导出」
  2. 在 筛选条件 表单中设置条件（可任意组合，留空即不限制）
  3. 点击 「🔍 搜索」，结果表格在下方显示并给出命中数
  4. 点击 一直存在的「⬇ 导出 xlsx」 按钮：浏览器下载 Excel，同时在服务器本地 exports/ 目录另存一份（显示完整路径）

筛选条件

筛选项选项 / 范围说明
名称 / NORAD / COSPAR 关键词自由输入同时模糊匹配名称、NORAD 编号与国际编号
对象类型PAYLOAD / ROCKET BODY / DEBRIS / UNKNOWN（多选）默认仅载荷（卫星）
国家 / 地区中文关键词（自由输入）对中文国家名模糊匹配，如 中国 / 美国 / 俄罗斯；优先 UCS 国家全称，否则 SATCAT 国家代码映射为中文
轨道类型全部 / 仅太阳同步(SSO) / 排除SSO / LEO / MEO / GEOSSO 用 J2 进动率严格判定（见下）
是否受控（推定）全部 / 仅受控(推定) / 仅存疑载荷且在 UCS 运营库或 DISCOS 活跃 → 受控
RCS 尺寸等级SMALL / MEDIUM / LARGE（多选）SATCAT 雷达截面积分类
平均高度范围最低 / 最高 (km)由最新平均运动反推半长轴计算（a−Rᴇ）
倾角范围0–180° 滑块轨道面与赤道面夹角
偏心率上限0–1 滑块1.0 表示不限制
质量范围最小 / 最大 (kg)0 表示不限制；优先 DISCOS 实测，回退 UCS 发射质量
📦 结果不设上限：返回全部符合条件的目标（按平均高度升序），可一次性导出完整清单。
💡 当前检索范围为 在轨对象（无 decay_date）。条件留空即代表不限制；多个条件之间为「与」关系。

计算字段与口径

字段计算 / 来源
平均 / 近 / 远地点高度由最新平均运动 n 反推 a=(μ/n²)^(1/3)，μ=398600.4418，Rᴇ=6378.137；平均高度=a−Rᴇ
线速度（平均/近/远地点）平均=√(μ/a)；近/远地点用活力公式 v=√(μ(2/r−1/a))
角速度轨道平均角速率=平均运动 n，给出 °/s 与 rad/s
太阳同步(SSO)J2 升交点进动率 Ω̇=−1.5·n·J2·(Rᴇ/p)²·cos i；判据 |Ω̇−0.98565°/day|<0.07 且 e<0.05 且 95°<i<102°；并给出该高度理论 SSO 倾角
质量 / 尺寸质量优先 ESA DISCOS 实测、回退 UCS；尺寸=DISCOS 平均截面积+形状，等效尺寸=2√(A/π)；另附 SATCAT RCS 等级
可控（推定）库中无「姿态可控」直接字段；以「载荷 且（在 UCS 运营库 或 DISCOS 活跃）」作为最佳代理指标，请结合实际核实

导出 xlsx

⬇ 一键导出 Excel

导出

导出按钮始终可见（搜索出结果后可用）。点击后：

  • 浏览器下载 catalog_search_YYYYMMDD_HHMMSS.xlsx；
  • 同时在服务器本地 exports/ 目录另存同名文件，并在页面显示完整路径；
  • 工作簿含两个 sheet：搜索结果（33 列规范中文表头）与 字段与口径说明。

REST API 接口

同样能力通过 REST 暴露，便于编程化批量获取与集成：

方法 / 路径说明
POST /api/v1/catalog/search请求体为筛选条件（JSON）；?format=json 返回 {count, results}，?format=xlsx 直接返回 Excel 附件
# 导出 600–800km 太阳同步载荷为 xlsx
curl -X POST "http://<host>:8502/api/v1/catalog/search?format=xlsx" \
     -H "Content-Type: application/json" \
     -d '{"object_types":["PAYLOAD"],"alt_min":600,"alt_max":800,"orbit":"仅太阳同步(SSO)"}' \
     -o catalog_search.xlsx
💡 在 /api/docs（Swagger UI）中可直接试用该接口，标签为「目录检索」。

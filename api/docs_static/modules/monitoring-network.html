数据库查询及导出

场景 三大要素库检索与批量导出（XLSX / CSV）：空间物体监测设备、空间天气监测设备、全球测控站。

本模块依据研究报告 docs/空间监测数据库构建.md，并多渠道拉取合并去重 （SatNOGS / INTERMAGNET / GIRO / SuperDARN / Space-Track / DISCOSweb launch-sites·organisations / Brahe 社区地面站 / Starlink 社区网关 / 公开站策展）落地要素库；渠道统计见 data/monitoring_network/CHANNEL_STATS.md。使用 PostgreSQL + PostGIS （geometry(Point,4326) + GiST）存储站点坐标。数据不进入 v_unified_objects 在轨目标视图，为独立专题库。

使用步骤

  1. 左侧导航点击 「监测与测控网络」
  2. 在标签页间切换：空间物体监测 / 空间天气监测 / 全球测控站 / DISCOS 发射场 / DISCOS 组织
  3. 可用名称关键词、网络多选、国家/地区中文关键词筛选
  4. 表格下方展示地基站点散点地图（天基设备不画点）

① 空间物体监测设备 external_ssa_sensors

覆盖官方与军民（SSN / TraCSS）、学术与区域（ESA DISCOS / ISON / TMDS）、商业（LookUpSpace SORASYS）等渠道示例节点。

字段说明
sensor_id / name / name_cn唯一 ID 与中英文名称
sensor_classspaceborne / ground_radar / ground_optical / network_node
network / operator / country所属网络、运营方、国家（中文）
lat / lon / alt_m / geomWGS84 坐标与 PostGIS Point
frequency_band / capability频段与监测能力描述

② 空间天气监测设备 external_space_weather_sensors

覆盖 NOAA SWPC、GOES-R、NASA Aura、ESA INTEGRAL、EISCAT / Tromsø、INTERMAGNET、GIRO、APIS、子午工程等。

字段说明
sensor_classspaceborne / magnetometer / ionosonde / isr / optical_uv / network
observablesTEC / F10.7 / Kp·Ap / 高能粒子 / 极光 等
data_formatNetCDF / HDF5 / CSV / REST 等

③ 全球测控站 external_ttc_stations

覆盖 ESTRACK、NASA DSN、USGS Landsat、KSAT、AWS Ground Station（Brahe 精确坐标）、 Azure Orbital（已退役历史近似点）、ATLAS / Leaf / NEN / SSC / Viasat、 SatNOGS 全量、Starlink 社区网关（≈360+）、DISCOS 发射场镜像，以及 ThumbNet 枢纽与中国测控网代表站。

字段说明
station_typedeep_space / near_earth / polar / commercial_gsaas / crowdsourced / launch_site
antenna_diam_m / bands天线口径与频段（S/X/Ka/UHF…）

④⑤ DISCOS 发射场 / 组织

external_discos_launch_sites（DISCOSweb /api/launch-sites）与 external_discos_organisations（/api/organisations）。需 .env 中 ESA_DISCOS_TOKEN；强制刷新：--refresh-discos。

⑥⑦ EsaLOF / EsaLOG（DISCOSweb v2 API）

请求头必须声明版本（否则易踩坑）：

Authorization: Bearer <ESA_DISCOS_TOKEN>
DiscosWeb-Api-Version: 2
Accept: application/vnd.api+json
  • EsaLOF external_discos_esalof — GET /api/fragmentations?include=objects （注意路径是 fragmentations，不是部分文档写的 fragmentation-events）。 含解体时间、eventType、评论，以及关联物体 mass / xSectAvg(RCS)。≈673 场。
  • EsaLOG external_discos_esalog — GET /api/initial-orbits?filter=and(ge(sma,40000000),le(sma,45000000))&include=object （SMA 单位为米；GEO 带 40–45 Mm）。按物体去重，保留最接近 GEO 的轨道。≈1400+。
💡 摄入：python scripts/ingest_discos_esalof_esalog.py --refresh --sync-events
公共客户端：scripts/discos_client.py。测控网三库仍用 python scripts/ingest_monitoring_network.py。 ThumbNet 全量节点仍需自备 CSV/JSON。
